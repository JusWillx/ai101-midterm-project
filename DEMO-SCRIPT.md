## Questions you may get
**Does the AI modify photos?** No. AI assisted coding; there is no live AI API or image editor.  
**Are Shelby images of the same car?** The showroom pair is sourced as front and rear of the same auto-show display; homepage hero is separate.  
**Did you test it?** Show actual test results, explain any failures, and distinguish source checks from live browser tests.  
**What changed through the pull request?** Show the genuine issue, branch, code diff, review and merged/open status.
