# VRT Garage — Coding Assistant Instructions

Read `README.md` before changing code. VRT Garage is an AI 101 midterm prototype for car enthusiasts who want to explore vehicles and eventually preview cosmetic modifications.

## How to work
- Work on **one requested feature at a time**. Explain a short plan before editing.
- Keep the project beginner-friendly: plain HTML, CSS, and JavaScript. Preserve the dark/charcoal/red design and working showroom.
- Preserve the vehicle selector and Shelby front/rear gallery, including accurate photo credits, keyboard accessibility, and image-error fallback.
- Ask before introducing paid services, new dependencies, accounts, or APIs. Use public example data; never add passwords, API keys, sensitive user data or real vehicle-owner information.
- Do not claim the site edits car photos or saves modifications; those are future features.
- Make changes on a separate Git branch and propose a pull request for human review. **Do not merge automatically.** Include the related GitHub issue number in the PR description.
- Describe the files changed and why; run available code checks and report precise results. Explicitly list browser actions that the student still needs to verify. Do not fabricate test results, screenshots, issue IDs, or a human review.
- Update `README.md`, `TEST-LOG.md`, and `AI-USE-NOTE.md` whenever a feature or limitation materially changes.

## Current status
The Stage 2.2 prototype lets people choose Shelby GT500, Nissan GT-R R35, and Toyota GR Supra. The Shelby has two photo views; other cars have one. Navigation is responsive. Paint selection, user photo uploads, and image editing are not implemented.
